# Sprout desktop app releases

Signed installers for the Sprout desktop capture app. Capture your screen, a window, or a region, mark it up, and send it to a Sprout board.

This repository holds release files only. Download from [getsprout.io](https://getsprout.io) or from the latest release:

- macOS (Apple Silicon and Intel): [Sprout-mac.dmg](https://github.com/MoJoActive/sprout-releases/releases/latest/download/Sprout-mac.dmg)
- Windows (x64): [Sprout-windows-x64-setup.exe](https://github.com/MoJoActive/sprout-releases/releases/latest/download/Sprout-windows-x64-setup.exe)
- Windows (ARM): [Sprout-windows-arm64-setup.exe](https://github.com/MoJoActive/sprout-releases/releases/latest/download/Sprout-windows-arm64-setup.exe)

The macOS app is signed with a Developer ID and notarized by Apple. The Windows installers are code signed.

Questions or problems: [getsprout.io](https://getsprout.io).
